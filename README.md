**Studio Canvas Pro**
A powerful and modern web-based canvas application designed for digital creators, designers, and artists.


**Features**:
- **Interactive Canvas**: High-performance drawing, dragging, and resizing tools.
- **Custom Layers**: Manage multiple layers, opacity, and blend modes easily.
- **Export Options**: Export your artwork in high-resolution PNG, JPEG, and SVG formats.
- **Responsive UI**: Clean, user-friendly interface optimized for desktop and tablets.


**Tech Stack**:
- **Frontend**: HTML5 Canvas, CSS3, JavaScript (or React/Vue if applicable)
- **Styling**: Tailwind CSS / CSS Modules
- **Build Tool**: Vite / Webpack
